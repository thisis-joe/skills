# Learning procedures

Apply the [common contract](../contracts.md). Use [research](research.md) for facts. [coco-learn](../../coco-learn/SKILL.md) owns mode selection, explanations and the [note format](../../coco-learn/references/note-template.md); this file adds the opt-in multi-session workspace.

## Opt-in multi-session learning workspace

Reuse existing learning files. With no convention, extend the note workspace (`INDEX.md`, `TEMPLATE.md`, `notes/`) with `MISSION.md`, annotated `RESOURCES.md`, `NOTES.md` for teaching preferences, sequential `learning-records/NNNN-slug.md`, short `lessons/*.html`, shared `assets/` and a learned-term `GLOSSARY.md`. Quick-reference material is kept as template notes rather than a second reference format. Keep one mission per workspace; unrelated subjects need separate state.

1. Establish one concrete mission with observable success, constraints and exclusions; when it is missing, ask why the user wants to learn before teaching. Use existing learning records and note status to find the next useful challenge, not coverage history.
2. Curate annotated high-trust knowledge sources before teaching domain facts and cite them; suggest optional practice communities. Respect a community opt-out; do not join or message one for the learner.
3. Produce short lessons with one tangible win, only necessary prerequisite knowledge, a recommended primary source and immediate feedback for practice.
4. Build retention through retrieval, spacing and interleaving where suitable; momentary fluency is not evidence of lasting understanding.
5. Reuse shared lesson styles/widgets and link each lesson to the template notes that hold its quick reference; create or update those notes when the lesson ends, because lessons are rarely reread and notes are. A lesson plus its shared assets must travel together when exported.
6. Record demonstrated understanding, stated prior knowledge/depth, corrected misconceptions and mission shifts. Covered material alone is not learned material.
7. Add glossary terms once understood, with one canonical term and its avoided aliases; revise definitions as understanding develops, and supersede conflicting learning records rather than erasing history.
8. Make quiz options comparable in length and vary correct-answer position. Confirm a changed mission before letting it redirect future lessons.

A learning record is a short title and one to three sentences: what is now known and why it changes what to teach next. Add a superseded-by status, evidence or implications only when they help. Merely covered material, terms already in the glossary and session logs do not get records.

Output: mission-aligned lesson, updated template notes and justified learning-state updates. Stop at the requested learning unit; a multi-session goal does not authorize scheduling reminders.
