# coco-whattosay

선택한 스킬에 지금 어떤 요청을 붙이면 좋을지 제안한다. 기본 흐름은 **선택 결과 확인 → 맥락에 맞는 요청문 추천 → 사용자 선택 대기 → 선택한 요청 실행**이다. [공통 계약](../_coco-shared/contracts.md)을 따른다.

## 1. 선택한 스킬과 목적 확인

직접 지정한 스킬을 우선하고, 없으면 앞선 대화에서 확정한 선택을 이어받는다. `coco-whichskill`의 선택 결과가 있으면 정확한 스킬 식별자·사용자 목적·확정 범위를 재사용한다. 단순 언급이나 추천 후보를 확정 선택으로 취급하지 않는다.

현재 사용 가능한 카탈로그와 실제 `SKILL.md` 위치를 대조하고 네임스페이스를 유지한다. 대상 스킬의 본문과 필요한 참조만 읽으며, 이 단계에서는 **요청문을 작성할 자료**로 취급한다. 대상 스킬의 실행 절차를 시작하거나 모든 스킬의 본문을 읽지 않는다.

선택 결과가 없거나 여러 후보로 모호하면 대상 하나만 확인한다. `coco-whichskill`이 없는 환경에서도 스킬 이름을 직접 받아 진행한다. 없는 스킬을 설치하거나 비슷한 스킬로 바꾸지 않으며, 본문을 확인할 수 없으면 그 한계와 필요한 위치를 알리고 실행 가능한 추천으로 제시하지 않는다.

대화에서 합의한 목적·범위·제약과 현재 관련 자료를 읽기 전용으로 확인한다. 이미 정한 내용은 다시 묻지 않는다. 대상을 알아도 작업 목적이나 필수 입력이 없어 유효한 요청문을 만들 수 없다면 그 정보만 질문하고 기다린다. 경로·티켓·승인된 계획을 지어내거나 빈칸을 채운 것으로 간주하지 않는다.

## 2. 요청문 추천

기본 3개를 제안하되 유효한 대안이 적으면 개수를 줄인다. 모든 옵션은 **같은 선택 스킬**의 지원 범위 안에서 사용자의 목적에 기여해야 한다. 목적·집중할 문제·작업 범위·기대 산출물에 의미 있는 차이를 두고, 표현이나 설명 길이만 바꾼 선택지는 만들지 않는다.

각 옵션에는 다음을 붙인다.

- 고유한 번호와 짧은 제목.
- 현재 맥락에서 이 옵션이 유용한 이유 한 줄.
- 정확한 스킬 호출 이름과 요청 내용을 함께 적은, 복사해서 사용할 수 있는 전체 호출문.

가장 적합한 하나에 **추천**을 표시하고 이유를 밝힌다. 요청문에는 필요한 대상·할 일·범위·기대 결과를 담고 이미 합의한 제약을 유지한다. 사용자가 작업 하나를 원하면 모든 옵션을 그 범위에 맞추며, 연속 실행이나 외부 게시를 새로 끼워 넣지 않는다. 아직 결정되지 않은 정책을 추천문에서 확정 사실로 만들지 않는다.

선택한 스킬과 현재 목적을 짧게 밝힌 뒤 옵션을 제시하고, **번호를 고르면 해당 요청을 실행한다**고 안내하고 답을 기다린다. 가용한 질문 도구나 최종 응답으로 선택받는다. 추천 표시 자체는 사용자 선택이 아니다.

## 3. 선택·수정·실행

- 유효한 번호를 고르면 **마지막으로 보여준 옵션**의 스킬과 전체 요청문으로 실행한다. 번호와 문장의 대응을 대화에서 유지하며 복원할 수 없으면 다시 확인한다.
- “2번인데 이 파일만”처럼 선택과 수정을 함께 주면 수정한 범위를 반영한다. “다른 옵션”, “더 좁혀줘”처럼 추천 수정을 요청하면 새 옵션을 제시하고 다시 선택을 기다린다. 모호하거나 유효하지 않은 선택은 실행하지 않고 확인한다.
- “문장만”, “추천만”을 요청한 경우 선택 후에도 완성된 호출문만 제공한다. 이 의도는 후속 수정에도 유지하며, 사용자가 실행을 요청하면 실행 단계로 넘어간다. 취소하면 종료한다.
- 실행할 때는 런타임의 지원되는 스킬 호출 방식을 사용하거나 선택한 `SKILL.md`를 읽어 그 절차를 적용한다. 호출문을 셸 명령으로 실행하지 않는다. 실제 실행에 필요한 도구·자료·권한은 해당 스킬과 기존 사용자 승인 범위에 따른다.

추천 단계의 결과는 옵션과 선택 대기까지다. 선택 후의 작업은 해당 스킬이 담당하며 실제 결과와 미완료 조건을 그 절차에 맞춰 보고한다.

예: `$coco-whattosay coco-review`는 현재 작업에 맞는 리뷰 요청문을 제안한다. `$coco-whattosay coco-review 요청 문장만 추천해줘`는 번호를 골라도 실행하지 않는다. 스킬을 이미 골랐다면 `$coco-whattosay`만으로 이어받으며, 스킬 탐색·설명 자체가 목적이면 `coco-tellmeskill`을 사용한다.
