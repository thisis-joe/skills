# 모든 스킬에 적용하는 공통 설명 양식

COCO·시스템·플러그인 등 대상의 종류와 관계없이 아래 양식을 그대로 사용한다. 간단 설명과 상세 설명도 같은 제목·항목·순서를 따른다. 다른 제목으로 바꾸거나 항목을 합치거나 생략하지 않는다.

## 출력 양식

**<정확한 스킬 식별자> — <간단 설명 또는 상세 설명>**

**목적:** 이 스킬이 해결하는 문제와 역할.

**사용 시점:** 실제로 적합한 요청이나 상황.

**입력:** 필요한 사용자 정보·대상·기존 자료.

**진행 방식:** 핵심 단계, 판단 기준과 필요한 선택.

**결과:** 사용자가 받는 산출물이나 판단.

**사용 예:** 해당 스킬의 올바른 호출과 구체적인 요청 예 하나.

**주의사항:** 실제 의존성, 지원 조건, 실행·권한 경계와 확인되지 않은 내용.

**원문:** 읽은 `SKILL.md`의 클릭 가능한 절대 경로와 필요한 연결 자료.

## 모드에 따른 분량

| 모드 | 내용의 깊이 |
|---|---|
| 간단 설명 | 각 항목을 한 줄로 작성한다. 진행 방식도 핵심 흐름만 짧게 잇는다. 예시는 하나만 제공한다. |
| 상세 설명 | 같은 여덟 항목 안에서 필요한 설명을 늘린다. 진행 방식에는 주요 단계·분기·종료 조건을, 결과에는 산출물과 완료 판단을, 주의사항에는 확인된 제약을 구체적으로 적는다. 예시는 하나를 설명과 함께 풀어쓴다. |

원문에 정보가 없으면 해당 항목에 “원문에 명시되지 않음”이라고 쓴다. 해당하지 않는 것이 확인되면 “해당 없음 — <이유>”라고 쓴다. 읽기 실패 시 주의사항에 “원문을 읽지 못해 카탈로그 정보만으로 안내함”을 밝히고, 원문 항목에는 접근하지 못한 위치와 상태를 적는다. 어느 경우에도 항목은 유지하며 빈 내용을 추측으로 채우지 않는다.

이 양식은 선택한 스킬을 **설명하는 출력**에만 적용한다. 해당 스킬을 나중에 실제 실행할 때의 산출물 형식을 변경하지 않는다.
