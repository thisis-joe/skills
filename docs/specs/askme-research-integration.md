# Askme research integration

## Agreement

Unify exploration, evidence-backed answers and optional quizzes under coco-askme. Keep coco-research as a compatibility alias with no independent procedure. A bare invocation of either name offers up to three current-session concepts with one-line relevance and free-text entry, without starting research or a quiz. An explicit question bypasses menus; explicit quiz requests retain answer withholding and one question per turn.

Use visible context first. Compaction or missing work continuity permits bounded recovery from a supplied task/handoff pointer or session-linked change only. Never infer session ownership from a branch or timestamp alone. If recovery remains insufficient, disclose the limitation and ask for a target. No repository, transcript or web sweep before selection. Wide means topic orientation; deep means evidence gathering only when needed. Neither is a separate executable skill.

Preserve source citations, installed-version checks, historical-intent uncertainty, evidence gaps, research constraints for subsequent changes and requested cited findings artifacts. Keep learning read-only; personal note capture remains in coco-til. Do not replace existing installed TIL behavior with the older learn bundle.

## Acceptance

1. Both bare names reach the same bounded topic menu; explicit questions and quizzes bypass it.
2. Sufficient context needs no content-discovery tool calls. Missing context allows one bounded recovery batch of at most two known sources, then stops; this is an opening cost bound, never a waiver of evidence checks after selection.
3. Compressed-context recommendations identify their evidence boundary and allow a different topic. A handoff retains concepts, unresolved questions and source pointers without automatically saving files.
4. Deep research is triggered by evidence gaps or changed scope/version/revision, not every answer or incorrect response. Reuse matching verified evidence.
5. Research primary-source/version/intent safeguards and existing quiz controls remain reachable. Upstream evidence is frozen; mappings identify the new owner.
6. Validate package, run the full unit suite, inspect changed and preserved scenarios in isolated fixtures, and use installer preflight before any authorized install. Record independent/runtime evidence limits honestly.
