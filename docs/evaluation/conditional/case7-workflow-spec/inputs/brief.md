Specification only for my repeated notes-to-report workflow. On a manual request after Friday's last meeting, collect that week's local notes and draft the usual weekly report into reports/. The operator resolves priority/owner ambiguity before finalizing. Never auto-post or send messages. Keep links back to the exact note paragraph. I often lose track of which note version was included, and reruns duplicate report files. Existing local tools are listed in tools.json. Scheduling or execution is not requested. The accepted report has Summary, Decisions, Actions (owner/due), Risks and Source notes headings. Existing reports are durable and must never be silently overwritten.
