# 팀 맞춤 스킬 수정 확인

`coco-updateskill`은 수정할 기존 스킬과 팀 요구를 확인하고, 유지보수 원본에서 규칙·관련 참조·출처 처리·안내를 함께 고칩니다. 목적과 호출 정책은 요청 없이 바꾸지 않으며, 검증·작업별 커밋 뒤 지원 설치기로 반영한 결과를 따로 확인합니다. 제안만 요청한 경우나 개인 수정본 충돌은 별도 상태로 처리합니다.

[적용 보고서](report.md)와 [구조화 결과](results.json)는 새 컨텍스트 한 에이전트가 작성한 작은 팀 패키지에 대한 세 가지 적용을 기록합니다. 두 진입점, 공통 규칙, 합성 원문·체크섬·대응표, 실제 검사 명령, 로컬 설치본과 개인 파일을 사용했습니다.

| 사례 | 실제 결과 |
|---|---|
| 팀 검사 명령과 공통 영향 확인 규칙 수정 | 관련 파일 8개만 변경·검증·커밋. 공통 규칙은 한곳에 두고 호출자를 연결. 고정 원문·원본 사실·UI 정책/의존성 유지. 임시 설치본과 원본의 관리 파일 해시 일치 |
| 개선안만 요청 | 구체적인 제안 문서만 작성. 원본·설치본·브랜치·HEAD 유지. 커밋·설치 없음 |
| 개인이 관리 설치 파일을 수정한 상태 | 원본 검증·커밋 완료. 설치 사전 확인은 exit 2로 차단. 개인 수정과 모든 설치 파일·소유 manifest 보존. 설치 완료로 보고하지 않음 |

작성자의 [별도 읽기 확인](parent-readback.json)으로 각 사례의 실제 파일과 설치 해시·커밋을 재조회했습니다. 읽은 지침은 적용 전후 및 현재와 같은 해시입니다. 초기 fixture 구성 실패와 수정은 원본 보고서·`setup-repair.txt`에 남겼으며 스킬 동작 결과에 섞지 않았습니다.

[이번 실제 설치](installation.json)는 사용자 스킬 폴더의 25개 스킬/81개 파일 일치와 기존 다른 항목 50개 보존, 동일 재설치 `unchanged`를 기록합니다. [루트 검사](root-checks.json)에서 기존 테스트 23개, 새 스킬 형식과 전체 패키지 검사가 통과했습니다.

이 평가는 자기 작성 fixture·요청·검사를 사용한 한 번의 제한된 적용입니다. 임의의 팀 규칙, 자기 자신 수정, 플러그인 캐시, 모든 원본 버전 갱신, 실제 외부 게시를 검증한 것은 아닙니다. 행동 준수나 모델 신뢰도의 일반적인 보증을 주장하지 않습니다.

원본 보고서와 명령 기록의 `/tmp/…`는 당시 경로입니다. `export.json`은 보존 파일 해시를, `git-history/`는 세 임시 저장소의 이력을 bundle로 기록합니다. 중첩 `.git`·캐시·심볼릭 링크를 제외했으며, 평가용 스크립트·합성 원문은 실제 설치 대상에 포함하지 않습니다.
