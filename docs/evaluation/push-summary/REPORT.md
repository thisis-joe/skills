# coco-push local forward application

The five bounded applications behaved as required: two branches were published through real local Git pushes, and three stopped before publication for an observed Jira write denial or a missing decision. No workflow failure was observed in this set. This is a single designed-fixture pass, not a claim of general reliability.

The exercise used real temporary working repositories, second peer checkouts, bare local remotes, fetched commits, merges, commits, branch renames, ordinary pushes, remote ref reads, and verified Git bundles. Jira was a clearly labeled **LOCAL MOCK**, implemented by `jira_adapter.py` against JSON files. No connector API, real Jira issue, real remote, installed skill, shared repository, or global Git configuration was changed. All exercise mutations were inside this temporary root.

The current `coco-push/SKILL.md`, both linked references, the common contract, and `coco-build` naming section were read. No earlier evaluation or parent conclusions were read. `skill-hashes-before.json` records the content before fixture application; `skill-hashes-after.json` and `skill-hash-comparison.json` show that all five complete files retained the same SHA-256 hashes. The version used is preserved in `skill-snapshot/`.

To reconstruct raw fixtures, copy `build_fixtures.py` into a **new empty temporary directory** and run it there. It derives its fixture root from its own path, uses only repository-local Git configuration, creates source/request/task records, and logs setup operations. Do not rerun it over this evidence directory. OIDs from a fresh setup may differ because commit timestamps differ; the bundles preserve this run's exact OIDs. To inspect the exact observed decisions, replay the recorded command order against copies of the bundles and before-task files, mapping the original temporary root to the new one and using the recorded pinned OIDs. `evidence.py` and `apply_common.py` are command-recording/mechanical helpers, not automated skill interpretation; the scope and stop decisions were made during the live application.
