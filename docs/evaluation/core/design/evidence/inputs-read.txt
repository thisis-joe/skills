brief.md
One receipt per order version to one address; two distinct order versions represent distinct intents. Provider supports idempotency keys and read-only lookup by key. Local DB can enforce unique intent key and transactional writes. No current public API compatibility obligation. Same intent with changed address must conflict. Delivery status is customer visible; a send timeout does not establish outcome. Maximum redelivery/replay horizon is 30 days, operations require retention 45 days.
