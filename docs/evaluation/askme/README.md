# coco-askme 적용 기록

선택한 작업·코드를 질의응답으로 학습하는 [새 스킬](../../../skills/coco-askme/SKILL.md)을 만들었다. 기본 흐름은 범위 선택 → 주제 선택 → 한 문제씩 질문 → 답변 피드백 → 심화 또는 전환이다. 팀 신규 절차이므로 고정 원문과 원본 대응은 변경하지 않았다.

## 대상과 방법

- 2026-10-20, 기능 브랜치 `feat/coco-askme`, 기준 `main` `37e6ef4`, 평가 시점 스킬 커밋 `e0f0f36`.
- 대상 프로젝트: `codereviewbot`(TypeScript·Node·zod·PostgreSQL), 브랜치 `codex/interactive-learning`, HEAD `21dc584`, 작업 트리 깨끗함.
- 작성자 대화를 상속하지 않은 에이전트 3개가 `SKILL.md`·`references/question-patterns.md`·공통 계약만 읽고 스킬을 수행했다. 각 에이전트에 5턴의 사용자 입력을 주고 전체 응답 기록을 받았다.
- 한계: 사용자 입력 5턴을 한 번에 전달했으므로, 턴마다 응답을 받은 뒤 다음 입력을 주는 방식보다 독립성이 약하다. 실제 클라이언트에서 진행한 대화가 아니다. 판정은 작성자가 응답 기록을 직접 검토해 내렸다.
- 평가 후 대상 저장소의 변경 경로는 0개였고, HEAD `21dc584`도 그대로였다.
