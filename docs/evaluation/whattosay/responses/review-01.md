`coco-review`로 주문 할인 변경을 검토하는 요청문입니다. 현재 `pricing.py`의 스테이징된 변경과 `tests/`의 수정·새 파일을 모두 포함하도록 했습니다.

1. **요구사항·규칙·품질 종합 리뷰 — 추천**

   할인 규칙, 기존 동작 보존, 테스트를 함께 확인하는 데 가장 적합합니다.

   ```text
   $coco-review README.md를 요구사항으로 삼아 pricing.py와 tests/의 현재 작업 변경을 리뷰해줘. 스테이징·미스테이징·미추적 파일을 모두 포함하고 기준 커밋·HEAD·검토 스냅샷을 기록해줘. 수량은 양의 정수라는 조건, 회원 10% 할인, 비회원 3개 이상 5% 할인, 할인 중복 금지, 기존 비회원 1개 주문 유지 여부를 확인해줘. 요구사항·저장소 규칙·품질/위험을 각각 판정하고 결함별 심각도·위치·근거를 알려줘. python3 -m unittest discover -s tests -v 결과와 검증 한계도 보고해줘. 리뷰는 읽기 전용으로 진행해줘.
   ```

2. **할인 경계값·회귀 집중 리뷰**

   회원 여부와 수량 1·2·3개에서 할인 조건이 갈리는 부분을 집중 확인할 때 유용합니다.

   ```text
   $coco-review README.md 기준으로 pricing.py와 tests/의 현재 작업 변경을 리뷰해줘. 스테이징·미스테이징·미추적 파일을 모두 포함하고 검토 기준과 스냅샷을 기록해줘. 회원·비회원과 수량 1·2·3개의 조합, 할인 중복 방지, 기존 비회원 1개 주문의 회귀 여부에 집중해줘. 조건별 기대 동작과 구현·테스트 근거를 대조하고 결함의 심각도·위치·실패 사례를 알려줘. python3 -m unittest discover -s tests -v 결과도 보고해줘. 리뷰는 읽기 전용으로 진행해줘.
   ```

3. **테스트 신뢰도 집중 리뷰**

   추가·수정한 테스트가 할인 요구사항을 충분히 검증하는지 확인할 때 유용합니다.

   ```text
   $coco-review README.md 기준으로 pricing.py와 tests/의 현재 작업 변경을 리뷰해줘. 스테이징·미스테이징·미추적 파일을 모두 포함하고 검토 기준과 스냅샷을 기록해줘. 테스트가 각 할인 규칙과 기존 동작을 검증하는지, 경계값 누락·느슨한 단언·잘못된 기대값·기존 검증 약화가 있는지에 집중해줘. 요구사항별 테스트 근거와 빈틈을 정리하고 결함의 심각도·위치를 알려줘. python3 -m unittest discover -s tests -v 결과와 추가로 필요한 검증을 보고해줘. 리뷰는 읽기 전용으로 진행해줘.
   ```

번호를 고르면 해당 요청으로 리뷰를 실행하겠습니다.
