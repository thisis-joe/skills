# Evidence layout

- `capability-controls.tar.gz`: native execution/resume checks, original failed
  abrupt-stop capability probe, semantic owner sensitivity controls, and all raw
  prompts/events/metadata. The failed stop is not passing recovery evidence.
- `invalid-attempt/`: first attempted primary, invalidated by the trial-feedback
  loop. `invalidation.json` identifies two already-running lifecycle projects and
  sixteen explicitly not-executed projects. Two completed review runs remain in
  its native archive. None contributes to efficacy estimates.
- `overflow-control.tar.gz`: exact public CLI probes of both source copies,
  a D3-only repair and full clean control. Oversized-refund crash is a genuine
  additional manifestation of D3, not a fourth independent seeded root.
- `required-tests.log`: complete required unittest run after the corrected
  experimental driver; 152 tests pass. Later closure checks are recorded with
  the final report.
- `primary/results.json`, `analysis.json`, `tables.md`: all twenty actual attempts,
  failures retained, strict artifact/operational completion and the same four
  jointly completed lifecycle seeds in both conditions. Classifier labels are
  observations; blind audits correct their interpretation, not native history.
- `primary/native-evidence.tar.gz`: complete corrected cohort native records,
  frozen snapshot and portable Git histories for the nineteen stable projects.
  The quarantined timeout has no final product snapshot claim.
- `primary/judgments.json`: unblinded cold judgments, both hidden review controls,
  source-integrity flags and separately recorded grader costs. Original blind
  verdicts and packet-integrity checks are adjacent JSON files.
- `primary/judgments-evidence.tar.gz`: the twelve review packets, ten owner
  packets, external condition mappings, exact judge prompts and native traces.
- `primary/judge-input-provenance.json`: every review packet's six fixture files
  byte-match freshly generated hardcoded synthetic source; user projects and
  personal notes are excluded. The first native review-judge approval was
  rejected over possible external transfer; the same command was approved after
  this low-risk provenance check.
- `primary/freeze-check.json`, `closure-tests.log`: eight frozen harness hashes,
  skill snapshot, no active skill changes and final 152-test/validator results.

Each archive has an adjacent JSON with SHA-256 and byte count. Native archives
retain prompts, tool commands/results, process/thread IDs, actual usage, owner
classifications, decisions, outcome probes and source hashes. Stable projects
include ordinary files and portable Git bundles; their `.guide` is recoverable
from the frozen `snapshot/`. Uncertain cancelled projects never receive a final
immutable snapshot claim. Absolute paths in control records identify originals;
the analysis helper also accepts relocated `records/<id>/result.json`.
