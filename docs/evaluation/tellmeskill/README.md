# 스킬 안내 흐름 확인

사용자가 요청한 `coco-tellmeskill`을 추가했습니다. 현재 대화에서 제공하는 전체 카탈로그로 목록을 만들고, 대상과 설명 길이를 순서대로 선택받으며 선택한 원문을 설명합니다. 간단·상세 모두 [공통 양식](../../../skills/coco-tellmeskill/references/explanation-format.md)의 목적·사용 시점·입력·진행 방식·결과·사용 예·주의사항·원문 8항목을 같은 순서로 사용합니다. 대상 스킬의 작업을 실행하지 않습니다.

[최초 보고서](report.md)와 [생성 대화](transcript.md)는 새 컨텍스트의 한 에이전트가 네 항목의 지정 카탈로그로 적용한 기록입니다. 3사례의 응답 9개에서 단계별 대기·길이 변경·다른 대상 선택·직접 호출·미등록 대상 처리를 확인했고, 생성된 설명 4개가 같은 8항목을 유지했습니다.

이 과정에서 “번호와 정확한 이름을 모두 받는다”는 문구가 두 정보를 동시에 요구하는 뜻으로 읽힐 수 있음을 발견했습니다. 대상을 번호 **또는** 이름으로 받도록 고쳤고, 설명 길이도 1/간단·2/상세로 명확히 했습니다. 초기 보고서와 그때 읽은 원문의 해시는 수정하지 않고 보존합니다. [수정 후 숫자 선택 3턴](numeric-report.md)에서 2번 스킬을 고른 뒤 1번 설명 길이를 선택해 같은 대상의 간단 설명을 받는 경로와 공통 8항목 유지를 확인했습니다.

[설치 확인](installation.json)은 23개 스킬/75개 파일의 실제 설치·참조·바이트 일치와 기존 다른 항목 50개 보존, 동일 재설치를 기록합니다. 기존 자동 테스트 23개와 새 스킬 형식 검사가 통과했습니다.

이는 지정된 작은 카탈로그와 생성 대화에 대한 제한된 확인입니다. 실제 질문 UI나 전체 제품 카탈로그 조회를 실행한 것은 아니며, 반복 실험·맹검 비교·모든 모델에서의 준수를 주장하지 않습니다. 원문 `/tmp/…` 위치는 당시 실행 경로이며, 보고서와 대화를 같은 이름의 사본으로 보존했습니다.
