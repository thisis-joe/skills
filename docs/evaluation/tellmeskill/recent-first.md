# 최근 스킬 우선·묶음별 전체 목록 확인

사용자 요청: `coco-tellmeskill`을 아무 설명 없이 호출하면 최근 쓴 스킬 3개 정도를 보여주고, 거기서 고르지 않으면 모든 스킬 중에서 고르게 한다. 모든 선택지에 간결한 설명을 붙이고, 전체 목록은 스킬을 분류한 묶음별로 설명한다.

## 바꾼 동작

- 인자 없는 호출 → 최근 사용 스킬 최대 3개 + **전체 스킬 보기** 선택지. 각 선택지에 한 줄 설명.
- 최근 선택지를 고르지 않거나(“이 중엔 없어”, 전체 보기, 스킬이 아닌 답) 최근 기록이 없으면 → [목적별 묶음](../../../skills/coco-tellmeskill/references/skill-groups.md)으로 나눈 전체 목록. 묶음마다 한 줄 설명, 번호는 묶음을 넘어 연속.
- 대상을 지정한 호출은 설명 길이로, “전체 목록” 요청은 묶음별 목록으로 바로 간다.
- 최근 스킬은 현재 대화의 호출과 [도우미](../../../skills/coco-tellmeskill/tools/recent_skills.py) 결과로 고른다. 도우미는 현재 런타임이 **현재 작업 폴더**에 남긴 최근 30일 세션 기록에서 스킬 호출 표시(Claude Code의 `Skill` 도구 호출과 `<command-name>`, Codex의 `<skill><name>`)만 읽고, 식별자와 마지막 사용 시각만 출력한다. 요청 문장·인자·다른 작업 폴더는 읽거나 출력하지 않는다. 기존 “개인 기록 전체 탐색 금지” 결정과의 관계는 [결정 기록](../../../skills/_coco-shared/decisions.md)에 새 행으로 남겼다.

## 자동 검사

`tests/test_tellmeskill_recent.py` 9개: Claude Code·Codex 형식의 임시 기록으로 작업 폴더 한정(형제 폴더·다른 폴더·하위 에이전트 기록 제외, 워크트리·하위 폴더 세션 포함), 최신순·중복 제거·기본 3개, 30일 창, 카탈로그 필터와 자기 자신 제외, 기록이 없을 때 빈 결과, 출력에 요청 문장이 섞이지 않음을 확인한다. SKILL.md에 적힌 도우미 명령을 그대로 꺼내 실행하는 검사와, 묶음 표의 각 행에 설명·분류 기준이 있는지 보는 검사도 포함한다.

실제 이 저장소의 Claude Code 기록에 도우미를 실행하면 `coco-updateskill`이 최근 스킬로 나오고 `coco-tellmeskill`은 제외됐다(약 0.1초). 같은 폴더의 Codex 기록에는 명시적 스킬 선택 표시가 없어 빈 결과였다.

## 새 컨텍스트 재현

새 컨텍스트의 에이전트 하나가 바뀐 SKILL.md·묶음 기준만 읽고, 17개 항목의 지정 카탈로그(COCO·시스템·플러그인 혼합)와 모의 도우미 출력으로 4사례 7턴을 응답했다.

| 사례 | 입력 | 결과 |
|---|---|---|
| A | `/coco-tellmeskill` → “이 중엔 없어” → `14` | 최근 3개 + 전체 스킬 보기(모두 한 줄 설명) → 최근 선택지를 반복하지 않고 8개 묶음 설명과 연속 번호 1–17의 전체 목록 → 14번 `anthropic-skills:pdf` 확인 후 간단/상세 선택지(설명 포함) |
| B | `/coco-tellmeskill`, 기록 없음 | 한 줄 안내 후 묶음별 전체 목록 |
| C | 대화 중 `/coco-verify` 사용 후 호출 → “coco-security” | 대화 스킬을 맨 앞에 두고 도우미 결과와 합쳐 3개 → 최근 목록에 없던 정확한 이름을 바로 대상으로 선택 |
| D | `/coco-tellmeskill 스킬 전체 목록 보여줘` | 도우미 실행 없이 묶음별 전체 목록 |

재현 에이전트가 지적한 모호점 중 두 가지를 고쳤다. 도우미를 스킬 폴더에서 실행할 때 `--workspace`에 넘길 값이 스킬 폴더가 아니라 세션의 작업 폴더임을 명시했고, 질문 도구 사용 규칙이 목록 단계뿐 아니라 설명 길이 단계를 포함한 모든 질문에 적용되도록 앞으로 옮겼다. 묶음 안 정렬에서 네임스페이스 식별자의 순서, `loop` 같은 경계 항목의 묶음 선택은 판단에 맡긴다.

## 한계

지정한 작은 카탈로그와 모의 도우미 출력에 대한 한 번의 재현이며, 실제 질문 UI·전체 제품 카탈로그·반복 실험·모든 모델에서의 준수를 확인하지 않았다. 런타임의 세션 기록 형식은 공개 계약이 아니므로 형식이 바뀌면 도우미가 빈 결과를 내고 전체 목록으로 넘어간다. Claude Code의 긴 경로 축약이나 Codex 자체 워크트리처럼 작업 폴더 경로로 연결되지 않는 세션은 세지 않는다.
